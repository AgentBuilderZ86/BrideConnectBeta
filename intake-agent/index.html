Mes besoins

Vos besoins restent vivants après l'envoi. L'agent vous pose une question quand une information vieillit, vous soumet ce qu'il observe sur le terrain, et vous pouvez donner des nouvelles en une phrase, écrite ou dictée.

Instructions de l'agent d'intake

Ce que l'agent sait, comment il challenge et le format de sa réponse. Il les applique sur tous les canaux : web, e-mail, WhatsApp et Teams. Gardez la section « FORMAT DE RÉPONSE » intacte : l'application en dépend.

Grille de qualification du copilote DSI

Repères Valeur / Faisabilité, lecture bottleneck shift, trajectoires. Le format JSON en fin de texte doit rester identique.
